# Rustastic Automaton

`ram` allows you to ease the creation of a language lexer based on finite state machines.

## Usage

Add `ram` as a dependency in Cargo.toml:

```toml
[dependencies]
ram = "8.0"
```

See examples and docs at [https://docs.rs/ram](https://docs.rs/ram).
